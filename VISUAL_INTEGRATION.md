# Traffino — интеграция второго этапа

Этап 2 реализован в представлении, UI и аудио. Симуляция, маршруты, столкновения, очередь, сохранения, счёт и структура восьми смен сохранены. Дополнен `App.event`; `externalPause` теперь синхронизирует аудио и при добавлении внешней причины к уже открытой паузе/фоторежиму.

## События

| Hook | Представление / звук |
|---|---|
| directionOpened / directionClosed | жест, поворот, свисток, световой акцент, GO/STOP |
| danger | тревога / облегчение, отдельный короткий сигнал |
| collision | частицы, реакция, тряска с настройкой, мягкий impact |
| emergency | частицы на въезде, цветные маяки, различимые сирены |
| pedestriansStarted / pedestrianPassed | подтверждение перехода, эффект успешного выхода |
| highFlow | радость с cooldown, золотые частицы, музыкальный акцент |
| eventEnded / ended | музыкальный итог и экран результата |
| claim / buy | награда / открытие и анимация панелей |

Частицы ограничены 72 слотами. Анимация машин сбрасывается по serial повторно используемого слота. Геометрия города объединяется в инстансы по материалам; транспорт и пешеходы используют общие пулы. Логика не зависит от анимационного времени.

## Качество и ограничения

| Пресет | Плотность пикселей | Тени | Геометрия и декор |
|---|---|---|---|
| Low | до 1 | выключены | простые коробки, меньше ожидающих декоративных фигур, без птиц и ореола, до 4 частиц на событие |
| Medium | до 1,5 | 1024 | фаски, прохожие, птицы, световые пятна |
| High | до 2 | 2048 | полная версия |

Все реальные машины и переходящие пешеходы видимы на любом качестве. Световые пятна заменяют множество дорогих point lights. Нет SSAO, depth of field и многопроходного bloom: эти необязательные эффекты не нужны для чтения сцены. Камера плавно вращается и меняет масштаб; скрытие фотоинтерфейса убирает также toast.

Локальный GPU-прогон использует Chrome/SwiftShader, а не физический телефон. `artifacts/visual-report.json` содержит draw calls, треугольники, память геометрий/текстур и проверки границ пулов. Числа не являются замером FPS реального Android/iPhone. Перед выпуском нужны реальные устройства, 10–15 минут нагрузки и проверка SDK в консоли Яндекса; такой доступ в этой работе не использовался.

## Проверки и сборка

```
npm test
npm run test:browser
node scripts/browser-smoke.mjs --art
npm run test:browser:production
node scripts/audio-preview.mjs
npm run package
```

Art-проверка снимает меню на desktop/portrait/landscape, день/закат/ночь, транспорт и все quality presets; проверяет отсутствие исключений, размеры пулов и остановку звука. Основная browser-проверка проходит восемь смен, три дополнительных режима, настройки, покупки, сохранение, фото, клавиатуру, касания, паузы SDK и локальный fallback.

`public/assets` рекурсивно копируется в `dist/assets` и входит в ZIP вместе с лицензией Nunito. Служебные reference-листы, тестовые отчёты и DEV API в release не входят. Снимок первого этапа сохранён как `artifacts/core-stage1.zip`.
